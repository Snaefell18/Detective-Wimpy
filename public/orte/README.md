# Ortsbilder

Hier kommen die Hintergrundbilder der Schauplätze rein. Der Dateiname entspricht
der `id` aus `lib/locations.ts`:

| Ort            | Datei             |
| -------------- | ----------------- |
| Marktplatz     | `marktplatz.png`  |
| Baumhaus       | `baumhaus.png`    |
| Café Mondlicht | `cafe.png`        |
| Nachtpark      | `park.png`        |
| Turnhalle      | `turnhalle.png`   |
| Alter Hafen    | `hafen.png`       |

Empfehlung: Querformat, ca. 1200x800 px. Die App schneidet sie als breites
Banner zu, der untere Rand wird von einem Farbverlauf überlagert.

Neue Orte: Eintrag in `lib/locations.ts` ergänzen und PNG mit passendem Namen
ablegen - der Rest (Reisen, Anwesenheit, Spurenverteilung) passiert automatisch.
