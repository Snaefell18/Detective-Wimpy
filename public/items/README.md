# Gegenstandsbilder

Hier kommen die Bilder der Spuren/Gegenstände rein. Der Dateiname entspricht der
`id` aus `lib/items.ts`:

| Gegenstand        | Datei              |
| ----------------- | ------------------ |
| Lupe              | `lupe.png`         |
| Fußabdruck        | `fussabdruck.png`  |
| Haarbüschel       | `haarbueschel.png` |
| Zerknüllter Zettel| `zettel.png`       |
| Schlüssel         | `schluessel.png`   |
| Kekskrümel        | `kekskrumel.png`   |
| Verlorener Schal  | `schal.png`        |
| Alte Fotografie   | `fotografie.png`   |

Empfehlung: quadratisch, 256x256 px, transparenter Hintergrund.

Neue Gegenstände: Eintrag in `lib/items.ts` ergänzen und PNG ablegen - Claude
benutzt sie ab dann automatisch als mögliche Spuren.
